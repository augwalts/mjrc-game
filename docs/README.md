# docs — reviews, analyses and proposals

Working documents for the engine, the training programme and the dashboard.
Dated files are snapshots of what was true when written; the living record is
`tools/sim/experiments.js` (rendered by the panel's research archive).

| document | what it is |
|---|---|
| `ERA-LESSONS.md` | the cross-era retrospective: one lesson per era and the case for what comes next |
| `ERA3-REVIEW.md` | era 3 in depth — the null-on-chips era that produced the fold ruling |
| `ERA2-REVIEW-2026-08-28.md` | era 2 review (the saturation proof) |
| `TRAINING-ARCHITECTURE-REVIEW-2026-08-28.md` | architecture review of the training stack |
| `THREAT-DETECTION-ANALYSIS-2026-08-27.md` | threat-model quality analysis |
| `SIM-DASHBOARD-ROADMAP.md` | dashboard roadmap |
| `SIM-DIRECTORY-REORG-PROPOSAL.md` | proposed reorganisation of `tools/sim/` |
| `PANEL-HEADINGS-REVIEW.md`, `PANEL-REDESIGN-PROPOSAL.md` | panel wording and layout proposals |

Specs that define the product live at the repo root instead — `DESIGN.md`,
`RULES-HK.md`, `TERMINOLOGY.md`, `STRATEGY.md`, `ENGINE-AUDIT.md`, `REVIEW-GUIDE.md`.
