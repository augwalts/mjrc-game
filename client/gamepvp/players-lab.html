6 · The contract both read

PlayerSummary {
  id            string            // game player id; the Almanac resolves typed names to one when linked
  displayName   string
  handle        string | null     // @handle from the account; null for a typed offline name
  userNo        number | null     // member number; 0 = augwalts
  avatar        string | null     // data URI (game) or Google picture; null → letter
  linked        boolean           // false = an Almanac typed name with no account behind it
  bot           boolean
  presence      { state: "lobby"|"waiting"|"playing"|"live-table"|"offline",
                  hand?: number, handsBase?: number, room?: string, lastSeenAt?: string } | null
  rating        { online: number | null, provisional: boolean,
                  estimate: number | null, estimateGames: number, weekDelta?: number }
  record        { games: number, hands: number, worthPerHand: number | null } | null
  starred       boolean           // viewer-relative; false when signed out
}

GET /api/players?scope=friends|online|room:<code>|all&sort=rating|estimate|name   → PlayerSummary[]
GET /api/players/:id                                                          → PlayerSummary + datasets
RuleWhy
Order inside a row is fixed: star · identity · presence · numbersEyes learn one scan path across both products
Two ratings always, side by side, online in blue and estimate in ink, never blendedThey measure different things; blue marks the number the game itself earned
Numbers are mono and right-aligned; "—" for none; "·p" for provisionalColumns line up in any list length
Rows are hairline-separated inside one card, never a card eachThirty players must fit on a phone
Unlinked typed names get a dashed avatar and no handleHonest about what is an account and what is a name someone typed at a table
Presence phrases are shared strings: in the lobby · waiting at a table · playing · hand N/M · at a live table · offline · last seenSame words on both products, bilingual through the strings table
Gold is the star and nothing else in this moduleThe palette ruling: colour carries meaning or it does not appear
