Flower legibility — numeral placement and glyph size

The index numeral shipped on 2026-09-01: 52px in the top-left corner with a 4.2 halo, the motif scaled 0.78 and dropped 22 to clear it, and the numeral painted after the motif instead of before — every art function used to emit it first, so the flower drew straight over it. This page now renders the real production tile and varies only the one thing still open: the name glyph, which flower-lab.html never laddered — every rung there carries gl:{size:24}.

1 — the same art at every size it is actually drawn

A tile is one 100×140 drawing scaled by CSS, so a numeral of N renders at N × displayHeight / 140 real pixels. That is why one internal size cannot serve every surface: at 52 the index is 20.8px on the studio board and 55.7px on a 150px review tile — the same drawing, two completely different pictures. The ink column is what your eye gets; roughly 11px for a digit and 13px for a CJK glyph is where they stop being legible.

2 — two tiers: small surfaces vs large

.fidx (index) and .glyph (name) are now CSS hooks in both renderers — a presentation attribute loses to any CSS rule, so a surface can resize either without a second copy of the art, and recenterGlyphs is delta-based so it re-centres afterwards.
