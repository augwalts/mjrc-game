Flower legibility — numeral placement and glyph size

The index numeral shipped on 2026-09-01: 52px in the top-left corner with a 4.2 halo, the motif scaled 0.78 and dropped 22 to clear it, and the numeral painted after the motif instead of before — every art function used to emit it first, so the flower drew straight over it. This page now renders the real production tile and varies only the one thing still open: the name glyph, which flower-lab.html never laddered — every rung there carries gl:{size:24}.

1 — the name glyph — the one thing still open

A CJK glyph needs roughly 13–14px of rendered height before its strokes separate. On a 140-tall canvas: 24 gives 6.9px in the studio palette and 9.6px on the board — it never reaches legible at any size that ships. 36 gives 10.3 / 14.4; 42 gives 12.0 / 16.8.
